# minecraft-item-guessing

**[English →](README.md)**

一个 [DeepSeek Harness](https://github.com/Dominic789654/awesome-deepseek-harness) **技能（skill）**，用于辅助 AI 在《多个AI猜同一个Minecraft物品》里当**猜题人**——只用是非问题，尽可能少地问出对方秘密固定的完整答案。

> 出题人在开局前固定一个完整答案＝**本体 ＋ 必猜状态**（例如：朝南倒置含水涂蜡的氧化切制铜楼梯）。猜题人只能靠是非问题把它问出来。

## 为什么需要这个技能

策略来自同一道谜底的实测对局：

| 局次 | 走的路径 | 结果 |
|---|---|---|
| 局Ⅰ | 先问形状骨架 → 家族 → 穷举状态 | **23 问通关，猜错 0 次** |
| 局Ⅱ | 按材料横向点名（是不是雕像／避雷针／铜箱／锁链……） | 35 问中止，猜错 1 次 |

技能把局Ⅰ的路径固化成必须执行的四阶段路线，并把局Ⅱ的失误写成明令禁止的动作。

## 安装

```bash
git clone https://github.com/M1dsunmmer08/minecraft-item-guessing.git \
  "${DSH_HOME:-$HOME/.dsh}/skills/minecraft-item-guessing"
```

下次会话启动时自动被发现（会出现在技能目录里）。

## 用法

两种方式：

1. **在 DSH 会话里**——直接说"玩猜物品"或"我的世界猜物品"，AI 会加载本技能并担任猜题人。
2. **给任意其他 AI**——把 `assets/猜题人提示词-v2.md` 整份粘贴为系统提示词，然后发送"开始"。

## "优化"优化了什么

**硬规则**（判定、计分、禁令）逐字保留——多 AI 同题竞技的前提是判定口径一致、成绩可比。只重写了策略层：

1. **新增开局准备阶段**——第 1 问之前先建候选全集、骨架表、状态表；联网查询不计问题数，因此是必做动作而非可选项。
2. **形状口径拆分**——"形状由方块自身状态描述（楼梯 `shape`）"与"形状来自与相邻方块的延伸连接（墙／栅栏／锁链）"必须分成两个问题问。这正是局Ⅱ陷入死胡同的那个坑。
3. **必猜状态三步法**——先问"是否存在"→ 再问"共有几项"→ 最后逐项确认取值；禁止跳步。
4. **提交闸门**——三步未完成不得提交最终猜测，堵死"先猜后补状态"。
5. **提问路线重写**——把原来空泛的"选择能有效区分候选的问题"换成硬性四阶段顺序，并明确禁止按印象横向点名。

## 适用范围

- 面向 Minecraft **Java 版**（具体版本由出题人声明；若版本高于模型知识截止，必须联网核实，禁止凭记忆断言"不存在"）。
- 路线与版本无关：任何"方块＋状态"组合都按同一套四阶段流程走。
