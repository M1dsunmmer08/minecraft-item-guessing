# 方块状态穷举表（阶段3 用）

**用法**：进入阶段3 时从上往下扫，每个状态先问"是否存在"，再问"取值"。不要背，照着扫。
**版本注意**：本表为通识清单。用户声明的版本（如 Java 26.3）可能高于你的知识截止，凡涉及某方块是否支持某状态，一律联网核实，禁止凭记忆断言"不存在"。

---

## 0. 先分清两层"必猜项"

完整答案里的"必猜项"来自两个不同层级，提问方式不同：

| 层级 | 含义 | 例子 | 提问方式 |
|---|---|---|---|
| **A 层：ID／名称变体** | 属于方块 ID 本身，不是 blockstate | 氧化档（斑驳／风化／氧化）、涂蜡（waxed）、颜色（16 色）、树种、图案、木质/石质变体 | "是否要求指定氧化阶段？""是否涂蜡？""是否要求指定颜色？" |
| **B 层：方块状态 blockstate** | 同一方块 ID 下的状态字段 | facing、half、shape、waterlogged、axis、open、powered、age… | "是否要求指定朝向？""是否要求指定半位？" |

**漏掉任何一层都会导致提交必错。** 铜类方块最常见的组合是：A 层两项（氧化档＋涂蜡）＋ B 层三到四项（facing＋half＋shape＋waterlogged）。

---

## 1. 通用方块状态总表

| 状态名 | 取值 | 典型方块 | 提问句式 |
|---|---|---|---|
| `facing` | north / east / south / west / up / down | 楼梯、门、活板门、朝向型方块、漏斗、按钮、拉杆 | 是否要求指定水平朝向？是否南北向？是否 south？ |
| `axis` | x / y / z | 原木、柱状方块、玄武岩、锁链 | 是否要求指定轴向？是否沿 X／Y／Z 轴？ |
| `half` | top / bottom | 楼梯、台阶、活板门、门 | 是否要求指定上半格还是下半格？是否 top？ |
| `shape` | straight / inner_left / inner_right / outer_left / outer_right | 楼梯 | 是否要求指定转角形态？是否直形 straight？ |
| `waterlogged` | true / false | 楼梯、台阶、栅栏、墙、铁栏杆等可含水方块 | 是否要求含水状态？是否为 true？ |
| `open` | true / false | 门、活板门、栅栏门 | 是否要求开启状态？ |
| `powered` | true / false | 按钮、压力板、红石元件、铁轨、门 | 是否要求处于激活／充能状态？ |
| `lit` | true / false | 红石灯、熔炉、营火、蜡烛、红石矿 | 是否要求处于点亮状态？ |
| `hinge` | left / right | 门、活板门 | 是否要求指定合页方向？ |
| `rotation` | 0–15 | 告示牌、旗帜、头颅 | 是否要求指定旋转角度？ |
| `age` | 0–N（随方块） | 农作物、甘蔗、仙人掌、可可豆、下界疣、甜浆果 | 是否要求指定生长阶段？ |
| `stage` | 0 / 1 | 树苗等 | 是否要求指定生长阶段？ |
| `snowy` | true / false | 草方块、灰化土、菌丝体 | 是否要求覆雪状态？ |
| `distance` / `persistent` | 1–7 / true·false | 树叶 | 是否要求指定树叶的衰减距离或是否持久？ |
| `level` | 0–N | 炼药锅水位、堆肥桶、含水方块 | 是否要求指定液面／填充等级？ |
| `bites` | 0–3 | 蛋糕 | 是否要求指定被吃的口数？ |
| `delay` | 1–4 | 中继器 | 是否要求指定延迟档位？ |
| `mode` | compare / subtract 等 | 比较器 | 是否要求指定工作模式？ |
| `instrument` / `note` | 乐器名 / 0–24 | 音符盒 | 是否要求指定乐器或音高？ |
| `face` | floor / wall / ceiling | 按钮、拉杆、砂轮 | 是否要求指定附着面？ |
| `north`/`south`/`east`/`west`/`up` | none / low / tall，或 true·false | 墙、栅栏、铁栏杆、红石线 | 是否要求指定某一侧的连接形态？ |
| `extended` | true / false | 活塞 | 是否要求处于伸出状态？ |
| `conditional` | true / false | 命令方块类 | 是否要求条件模式？ |
| `disarmed` / `attached` | true / false | 绊线、绊线钩 | 是否要求指定绊线状态？ |
| `eye` | true / false | 末地传送门框架 | 是否要求已放置末影之眼？ |
| `pickles` / `eggs` / `candles` / `charges` | 1–4 等 | 海腌菜、海龟蛋、蜡烛、重生锚 | 是否要求指定数量／层数？ |
| `berries` | true / false | 洞穴藤蔓 | 是否要求结果状态？ |
| 变体类：颜色／树种／姿势／图案 | 16 色、树种、pose 等 | 羊毛、木板、铜傀儡雕像、旗帜 | 是否要求指定颜色／树种／姿势／图案？ |

## 2. 家族清单（阶段1–2 用）

**形状变体家族**（"不是完整立方体"的主要去处）
楼梯 · 台阶 · 墙 · 栅栏 · 栅栏门 · 门 · 活板门 · 地毯 · 压力板 · 按钮 · 告示牌 · 旗帜 · 床 · 蜡烛 · 花盆 · 火把 · 灯笼 · 锁链 · 铁栏杆 · 铜格栅 · 避雷针 · 头部／头颅

**整格方块家族**
矿物与金属块 · 石质变体（石头／深板岩／凝灰岩／黑石／砂岩／方解石／滴水石） · 木质方块 · 羊毛／混凝土／陶瓦／玻璃（含染色） · 自然方块（草、泥土、沙、冰、雪） · 下界方块（石英、地狱岩、灵魂沙） · 末地方块（紫珀、末地石） · 海洋方块（海晶石、海晶灯） · 功能方块（工作台、熔炉、箱子、发射器、信标、附魔台…）

**非方块类**
工具 · 武器 · 盔甲 · 食物 · 材料 · 药水 · 唱片 · 刷怪蛋 · 书与笔

## 3. 铜专表（最容易 35 问空手的一片区域）

| 维度 | 取值 |
|---|---|
| 氧化四档 | 铜 → 斑驳的（exposed）→ 风化的（weathered）→ 氧化的（oxidized） |
| 涂蜡 | waxed / unwaxed（蜜脾打蜡，锁定外观、停止继续氧化） |
| 切制铜衍生件 | 切制铜块 · 切制铜楼梯 · 切制铜台阶 · 铜格栅 · 铜灯 · 铜门 · 铜活板门 · 铜傀儡雕像 · 铜箱 |
| 楼梯类额外状态 | `facing` + `half` + `shape` + `waterlogged`（四层） |

**正确问法**：先问"是否属于铜家族" → 再问"是否属于切制铜衍生件" → 再问"是楼梯／台阶／格栅／灯／门／活板门／雕像／箱中的哪一类（逐项是非问）"。
**错误问法**：直接连问雕像、避雷针、铜箱、锁链、栏杆、门、活板门、灯笼——每问只排除一项。

---

## 4. 状态层数排行榜（判断"还差几问"）

| 层数 | 典型方块 | 必猜项构成 |
|---|---|---|
| 5 层 | 涂蜡氧化切制铜楼梯 | 氧化档＋涂蜡＋facing＋half＋shape（＋waterlogged） |
| 4 层 | 门类、活板门类、含水楼梯 | facing／half／hinge／open／powered／waterlogged |
| 3 层 | 墙、红石元件、告示牌 | 连接值／powered／rotation／attached |
| 2 层 | 台阶、原木、按钮 | type／axis／face／facing |
| 1 层 | 整格方块 | 多为无必猜状态 |

拿到"存在必猜状态（是）"后，先按候选方块所属家族预估层数：**楼梯类一律按 4–5 项追问，不要问两项就提交。**

---

## 5. 收尾复核

逐项确认完，把答案按提交格式口述一遍请出题人确认口径（属场外重述，不计问题数）。若不确定口径是否一致，改用一条正式问题复核，照常计数。
