# 提问策略：下一句该问什么

## 0. 总原则

**每一问都要尽可能砍掉一半候选。** 优先级：分类骨架 > 材质家族 > 具体候选 > 状态取值。

反例（砍不掉候选）：连问"是不是雕像／避雷针／铜箱／锁链／栏杆／门／活板门／灯笼"——每问只排除一个物品，属于"按印象点名"，是 30 问以上空手的头号原因。
正例（砍一半）："是否属于完整方块的形状变体家族"——一句把候选砍成"形状变体"与"非形状变体"两半。

---

## 1. 阶段1：骨架二分决策树

```
Q 能否作为方块放置 / 拿在手上？
├─ 否 → 非方块类（工具、武器、食物、材料、药水、唱片、刷怪蛋…）
└─ 是 → Q 是否占满完整 1×1×1 立方体？
        ├─ 是 → 整格方块分支：材质家族 → 功能 / 装饰 / 矿物 / 自然方块
        └─ 否 → ⚠️ 这是「纳入信号」：楼梯、台阶、墙、栅栏、门、活板门、
                地毯、压力板、按钮、告示牌、旗帜、床、蜡烛、植物、
                农作物、火把、灯笼、锁链、铁栏杆、头部方块全在此列
                Q 是否属于「完整方块的形状变体家族」？
                ├─ 是 → Q 台阶？→ Q 墙？→ Q 楼梯？→ Q 栅栏／栅栏门？→ Q 门／活板门？
                └─ 否 → 装饰小件 / 植物农作物 / 功能件（按钮、压力板、火把、灯笼、
                        花盆、蜡烛）/ 实体型方块（头颅、旗帜、告示牌、床）
```

**关键提醒**："不是完整立方体"绝不能用来说明"排除了楼梯台阶"——恰恰相反，这是把形状变体纳入视野的信号。失败局就是在第 3 问拿到这个"否"之后反向使用，之后 30 多问再没回到形状维度。

### 已证实的提速路径

获胜局实际路径（23 问通关）：

| 阶段 | 问数 | 内容 |
|---|---|---|
| 骨架 | 1–7 | 可放置 → 非完整立方 → 非植物 → 存在必猜状态 → 非木质 → 非染色 → **形状变体家族（是）** |
| 家族 | 8–12 | 台阶（否）→ 墙（否）→ **楼梯（是）** → 非石头 → **铜质（是）** |
| 状态 | 13–22 | 氧化档 → 涂蜡 → facing 存在 → 南北 → south → half 存在 → top → shape=straight → waterlogged=true |
| 提交 | 23 | 一次命中 |

**前 10 问锁定本体，后 10 问扫状态**——这是本玩法的标准节奏。若 15 问后仍未锁定本体大类，说明你漏了形状骨架这一层。

## 2. 阶段2：材质家族二分池

问法固定为家族层级，不问具体物品：

```
木质（含原木／木板／去皮／菌木）？
├─ 是 → 树种？（橡木／云杉／白桦／丛林／金合欢／深色橡木／红树／樱花／苍白／竹／绯红／诡异）
└─ 否 → 石质（石头／深板岩／凝灰岩／黑石／安山岩／闪长岩／花岗岩／砂岩／方解石／滴水石）？
        └─ 否 → 金属类：铜（含切制铜衍生／氧化／涂蜡）／铁／金？
                 └─ 否 → 其他：羊毛染料色／陶瓦／混凝土／玻璃／紫水晶／下界（石英、地狱岩）／末地（紫珀）／海洋（海晶）／黏土／红石／蜜蜡／骨头／纸
```

铜家族要点：铜与切制铜有**四档氧化**（铜 → 斑驳的 → 风化的 → 氧化的）＋**涂蜡/未涂蜡**，且切制铜衍生件包括：切制铜、切制铜楼梯／台阶、铜格栅、铜灯、铜门／活板门、铜傀儡雕像、铜箱。**先问"是否属于铜家族"，再问"是否属于切制铜衍生件"**，不要逐一点名。

## 3. 阶段3：状态穷举三步法

### 第一步：问存在

```
第N问：除本体名称外，答案是否还要求指定至少一项特殊状态？
```

### 第二步：问数量（二分逼近）

```
第N问：这些必猜状态是否多于一项？是否达到三项？是否达到四项？
```

拿到项数＝拿到"还差几问才能提交"，也顺手校准了候选。

### 第三步：逐项问类别与取值

按状态清单从上往下扫，**每个状态先问"是否存在"，再问"取值"**：

| 顺序 | 状态 | 特征问法 |
|---|---|---|
| 1 | 氧化档 / 涂蜡 | 是否含"处于特定氧化阶段"？是否涂蜡？ |
| 2 | facing 朝向 | 是否要求指定水平朝向？是否南北向？是否 south？ |
| 3 | half 半位 | 是否要求指定上半／下半格？是否 top？ |
| 4 | shape 形态 | 是否要求指定转角形态（直形／内角／外角）？是否 straight？ |
| 5 | waterlogged 含水 | 是否要求含水状态？是否 true？ |
| 6 | axis 轴向 | 是否要求指定轴向（x／y／z）？ |
| 7 | open / lit / powered / extended | 开关、点燃、充能类状态 |
| 8 | age / stage / level / bites / distance | 生长、液面、咬痕、堆叠层数 |
| 9 | rotation / hinge / mode / instrument | 旋转角、合页方向、模式、乐器 |
| 10 | 变体类（颜色／树种／姿势／图案） | 是否要求指定颜色、树种、姿势或图案？ |

**收尾复核**：把已确认项按提交格式口述一遍，请出题人确认口径（属场外重述，不计问题数；不确定就用一条正式问题复核，照常计数）。

---

## 4. 阶段4：提交

```
第N问：我猜完整答案是"〈状态描述＋完整物品名〉"，对吗？
```

- 一次只提交一个完整答案，不列备选。
- 必须包含全部必猜状态，本体必须精确到变体（不能说"某种铜楼梯"）。
- 三件事没做完不得提交：① 问过"是否存在必猜状态" ② 问过项数／类别 ③ 每项取值已确认。

---

## 5. 每题输出前的自检四问

1. 能明确答"是／否"吗？
2. 只含一个独立条件吗？
3. 问的是"能够具有"还是"当前具有"？
4. 形状／连接类问题，问的是**自身状态**还是**相邻延伸**？

---

## 6. 真实对局失误清单（照此自查）

| # | 失误 | 后果 | 正确动作 |
|---|---|---|---|
| 1 | 拿到"非完整立方体"后漏问形状变体家族 | 本体 35 问未锁定 | 紧接着问"是否属于形状变体家族" |
| 2 | 把"非整格"当作排除项反向使用 | 楼梯被错误排除 | 它是**纳入**信号 |
| 3 | 材料维度横向点名（雕像／避雷针／铜箱／锁链／栏杆／门／活板门／灯笼） | 整片"切制铜"家族从未进入候选 | 按分类做减法，先问"切制铜衍生件" |
| 4 | 候选池归零仍不推翻基础假设 | 陷入"铜傀儡雕像"死胡同 | 基数归零＝分类错了，立即回退重问形状 |
| 5 | 先提交猜测，再补问状态 | 第22问猜错一次 | 先问项数，再逐项确认，最后提交 |
| 6 | 把"形状随相邻改变（是）"与"水平延伸连接（否）"读成矛盾 | 误排除楼梯 | 楼梯 shape 属自身状态；延伸连接指墙／栅栏／锁链 |

### 分水岭示例（务必记住）

问："碰撞／轮廓是否因相邻同类方块向水平方向延伸连接？" → 答 **否**。
这个"否"排除的是**墙、栅栏、铁栏杆、铜格栅、锁链**这类延伸连接型方块，**不排除楼梯**（楼梯的形态由自身 `shape` 状态描述）。
失败局把它当成了排除楼梯的依据，直接走向死胡同；获胜局正确理解为"铜质候选收窄到楼梯"。

---

## 7. 卡住时的三条恢复动作

1. **回到形状骨架**：重问"是否属于形状变体家族／是否属于楼梯类"。
2. **请口径裁定**：用一句是非问题确认冲突回答的适用范围（不计问题数）。
3. **回退到最粗维度**：整格 / 非整格、方块 / 非方块、自然生成 / 合成获得，重新二分。
